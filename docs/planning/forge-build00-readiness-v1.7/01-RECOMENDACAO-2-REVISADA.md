# Recomendação 2 revisada

Esta página substitui, para a recomendação 2, o texto da v1.4. Não está aprovada. Não mexe na recomendação 1, nas contas, nos spikes, nos gates humanos nem no caminho da v1.6.

A v1.4 tratava Claude Code e AIOX como se fossem caminhos ou autoridades que podem discordar e decidir juntos. A base não diz isso.

## O que a base já escreve

- **AIOX.** Framework preferido de engenharia. A função escrita é organizar papéis, workflows e práticas de desenvolvimento. No caminho preferido, o Forge define missão, estado e política; o AIOX organiza a execução de engenharia; depois vem a engine. Fonte: FDP-06, seções 15 e 16, e FDP-16 v1.7. A história F-013 é o adaptador e o squad com escopo, não uma reescrita do AIOX. O AIOX não é o único caminho e não pode ser o único ponto de falha.
- **Claude Code.** É uma engine do primeiro produto utilizável, ao lado do Codex. O roteador escolhe a engine. O adaptador do Claude Code está na história F-012 e no SPIKE-03. Fonte: FDP-16 v1.7 e FDP-20. A base não diz que o Claude Code é o ambiente em que os agentes do AIOX são construídos.
- **Como se encaixam.** São camadas complementares no caminho preferido: AIOX organiza; Claude Code pode ser a engine que executa. Não são alternativas independentes nem duas autoridades do mesmo nível.
- **O outro caminho já escrito.** Se o AIOX não estiver disponível, o Forge chama a engine direto, só para ação interna, sem publicação e sem efeito externo. Isso é reserva de caminho, não disputa entre Claude Code e AIOX. A engine continua podendo ser o Claude Code. Deixar de preferir o AIOX exige decisão de mudança.

## O que esta revisão não escolhe

Não cria uma arquitetura nova. Não transforma o Claude Code em construtor dos agentes do AIOX, porque a base não diz isso. Não cria uma votação entre os dois. A frase da v1.4 que exigia acordo dos dois para classificar um detalhe técnico fica retirada desta recomendação.

Se você quiser uma relação diferente da que a base já escreve, isso é decisão sua. Esta página não a toma.

## Que divergência para o trabalho

Para o trabalho e vai para você:

- discordância sobre o que entra no trabalho ou sobre segurança;
- dúvida que não dê para classificar com segurança dentro da base já aceita;
- no caminho reserva, qualquer dúvida sobre escopo, segurança ou interpretação técnica. Só segue o que a regra da F-013 já permite com clareza. O Claude Code não resolve essa dúvida sozinho.

Não para o trabalho por uma disputa inventada entre AIOX e Claude Code. A base não dá a nenhum dos dois o poder de desempatar o outro. Se surgir uma discordância que a base não resolve sem escolher uma relação nova, o trabalho para e a questão vem para você.

Os outros gates humanos continuam. Esta página não os substitui. Segurança específica, mudança de escopo e liberação ou publicação seguem o que os documentos-base já exigem.
